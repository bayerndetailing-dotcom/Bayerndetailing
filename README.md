# Bayern Detailing

Eerste statische websiteversie voor Bayern Detailing.

## Bestanden
- `index.html` — de website
- `styles.css` — vormgeving
- `script.js` — menu en demo-contactformulier

## Lokaal bekijken
Open `index.html` in je browser.

## Cloudflare Pages
Upload deze map naar een GitHub-repository en verbind die repository met Cloudflare Pages.

### Build-instellingen
Omdat dit een eenvoudige statische website is:
- Framework preset: None
- Build command: leeg
- Build output directory: `/`
