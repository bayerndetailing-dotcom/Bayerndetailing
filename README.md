# Bayern Detailing — complete upload

Deze map is klaar om rechtstreeks naar de hoofdmap van je GitHub repository te uploaden.

## BELANGRIJK: juiste structuur

Je repository moet na upload EXACT zo zijn:

bayern-detailing/
├── index.html
├── styles.css
├── script.js
├── README.md
└── images/
    └── hero-before-after.jpg

De afbeelding moet dus NIET alleen in de hoofdmap staan.

## Test

Na Cloudflare deployment moet deze URL de foto tonen:

https://bayerndetailing.com/images/hero-before-after.jpg

Als dat werkt, werkt de hero ook.

## Upload

1. Download de ZIP.
2. Pak hem uit op je pc.
3. Open de uitgepakte map.
4. Selecteer ALLE bestanden én de map `images`.
5. Upload deze naar de HOOFDMAP van je bestaande GitHub repository.
6. Vervang bestaande bestanden.
7. Commit changes.
8. Wacht tot Cloudflare opnieuw deployt.
